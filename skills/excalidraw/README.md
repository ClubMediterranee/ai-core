# excalidraw

Generates [Excalidraw](https://excalidraw.com/) diagrams from natural language descriptions. Produces `.excalidraw` JSON files that can be opened directly in the Excalidraw editor or VS Code extension.

## Usage

Trigger with any phrasing like "create a diagram", "draw a flowchart", "visualize this architecture".

```
Create a flowchart showing the user authentication flow
Draw a system architecture diagram for a microservices setup
Make a mind map of the project structure
```

## Supported diagram types

- Flowcharts and process diagrams
- System architecture diagrams
- Relationship / entity diagrams
- Mind maps

## Output

A `.excalidraw` file in the current directory, ready to open in Excalidraw.
