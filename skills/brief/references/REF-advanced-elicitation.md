# Advanced Elicitation — Patterns

The protocol lives in `SKILL.md` (*Advanced Elicitation*). This file holds only the pattern lists.

**`[A]` asks what is missing, or cut where the PM would cut differently.** What is *malformed* is
the Challenge Pass's; a well-formed claim the evidence does not settle is *Challenge the
framing*'s. Pick the 2–3 patterns most relevant to the artifact at hand — never all of them. They
are prompts for your own reasoning, not a questionnaire: a question comes from what you found when
you looked, never from the list.

| Artifact | Pattern | What to look for |
|---|---|---|
| **Any** | Implicit assumption | Something treated as true across the artifact with nothing observed behind it |
| | Internal tension | Two things the PM said, or two inputs, that cannot both hold |
| | Reframe the question | Whether the stated problem is the real one — a better framing that would dissolve part of the brief |
| **Outcomes** | Proxy metric | The metric approximates the result — what could move it while the real result stays flat? |
| | No collection path | Measurable in principle, but nothing collects it today — who would instrument it, by when? |
| | Arbitrary threshold | A number with no reference — benchmark, history, comparable initiative |
| | Second-order effect | What reaching this outcome could degrade elsewhere, that no guard-rail watches |
| | Opportunity cost | What else the same investment could buy — is this outcome worth more than the alternative? |
| **Signals** | Missing observation | A signal that should exist if the problem is real, and that nobody cited |
| | Fragile convergence | An apparent pattern resting on signals of types too different to conclude |
| | Narrow signal scope | All signals from one market, segment or channel |
| | Source triangulation | A load-bearing claim resting on a single source type — which second, independent type would confirm it? |
| **Persona** | Loosely bounded persona | A trait that could fit two different people with different stakes |
| | Underestimated workaround | A workaround that makes the problem less urgent than it sounds |
| | Miscalibrated cost | A cost to the persona out of proportion with the signals, either way |
| **Key problem** | Scope ambiguity | A term of the statement that could mean two different things |
| | Inversion | What would *guarantee* this problem stays unsolved — and whether the brief already contains it |
| | Most likely failure | The single most probable reason the initiative fails — adoption, market, execution, or the problem definition itself — and what in the brief would change if it were true |
| **Opportunities & scope** | Symptom opportunity | A lever on a visible effect, not on the root cause |
| | Missing lever | A signal from Step 2 that no opportunity picks up |
| | Premature cut | Something removed that could return without harming the success signal — or whose absence harms it |
| | Assumed constraint | A constraint treated as fixed and never verified |
| | Behaviour-change resistance | The habit, learning cost or broken workflow that would keep the persona from changing, solution in hand |
