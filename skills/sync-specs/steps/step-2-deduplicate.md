# Step 2 — Deduplicate

Match the findings against what Step 0 loaded, **by key**. Titles drift as wording is polished; keys
do not. A key already covered means: propose to **attach a carrier** to the existing document, never
to open a second one on the same mechanism.

A run in which *every* finding is already covered creates no new rule id — the two gates then merge
into one, see Step 5.
